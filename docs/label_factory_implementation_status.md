# Flood-label factory implementation status

Status date: 2026-07-20. This inventory describes repository capability and the current governed Mae Sai engineering evidence, not completion of a real annotation campaign.

## Outcome

FloodGuard now has a tested active-learning and flood-label-factory engineering foundation with fail-closed contracts inside its declared, content-addressed artifact chain. The repository can hash and validate processed/common-grid evidence, validate source/grid contracts, materialize real aligned `sar_change_v2` pool features, preserve the weak polygon as positive-unlabeled per-query evidence, freeze an authority-approved whole-parent-tile calibration reserve into 12 blind calibration and 12 disjoint fresh-retest queries, build an internal-only operator queue, build model-blinded review packages, import immutable reviews, rasterize reviewer and calibration-authority geometry, freeze and score a fixed reviewer-calibration set, preserve confidential non-pass diagnostics without issuing a receipt, measure agreement, construct and import an adjudication queue, deterministically build canonical consensus cells, freeze an immutable JSON labelset, derive a release-bound training table, train a query-only logistic/HGB committee, select Round 0 and 60/20/20 later batches, and compare active review with random review at equal cost.

The real Mae Sai source pair, processing/alignment receipt, governed context, and canonical 32 x 32 query grid now exist in the controlled external workspace. FloodGuard still cannot honestly claim a real training labelset, a trained real-data committee, active-learning efficiency, geographic generalization, or decision-layer eligibility because the independent reference, reviewer, release, and multi-event evidence do not yet exist.

## Implemented artifact chain

```text
event/source registries + processed/coverage/valid-data/registration files
  -> self-hashed processing/alignment receipt
  -> governance-bearing v3 canonical-grid receipt + tile/query manifests
  -> sar_change_v2 cell pool + positive-unlabeled weak-query summary
  -> weak seed and/or Round 0 candidates
  -> internal selection manifest
  -> optional governed VV/VH/composite derivative-lineage receipt
  -> attributable Reference Authority design-approval package
  -> separate canonical calibration-reserve/reference construction
  -> blinded primary/secondary bundle
  -> fixed calibration reference + passing reviewer-calibration receipt
  -> locked annotation JSONL
  -> reviewer cell CSV + agreement JSON
  -> adjudication queue + adjudication JSONL
  -> canonical final cells + raster-lineage JSON + label content + consensus receipt
  -> raw-input-recomputed QA CSV + self-hashed receipt
  -> frozen labelset JSON
  -> release-bound training table + derivation manifest
  -> query committee directory
  -> region candidate CSV
  -> 60/20/20 internal selection + operator-only queue package
  -> next blinded bundle
  -> equal-cost evaluation
```

Every arrow after the blinded bundle requires evidence supplied by actual reviewers or the controlled external geospatial workspace. The repository validates that evidence but does not manufacture it.

## Current claims that are not allowed

Do not state that:

- the existing Mae Sai polygon is complete non-flood/flood truth;
- 65,536 cells are independent labeled observations;
- the legacy logistic score is calibrated flood probability;
- the label factory has improved flood detection;
- active learning has reduced annotation cost;
- a query committee can feed the dashboard flood layer, action classes, FPPS, or warnings; or
- an untouched geographic test exists.

The historical VV/VH ratio and combined-change columns remain in the explicitly
legacy weak-label experiment only. Canonical `sar_change_v2` intentionally uses
raw VV/VH plus direct dB changes and excludes those redundant, historically
ambiguous formulas; changing that choice requires a separately versioned
ablation schema rather than silently altering v2.

Allowed current claim:

> FloodGuard has implemented a reproducible, safety-labeled engineering workflow for selecting valuable human reviews and validating a content-addressed multiclass label corpus. Its declared artifact chain fails closed on missing or inconsistent provenance. Real human labels, adjudicated releases, cross-event experiments, and any later flood-model promotion remain pending evidence.
