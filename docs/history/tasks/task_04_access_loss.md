# Task 04 - Access-Loss Prototype

## Goal

Compare normal versus flood-disrupted access to shelters, hospitals, clinics, and main roads.

## Initial Output

- people losing 15-minute access
- people losing 30-minute access
- people losing 60-minute access
- travel-time increase
- source and confidence fields

## Acceptance

The prototype runs on sample roads, shelters, facilities, and population fixtures without requiring private data.
