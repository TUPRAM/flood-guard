# Licensing Request Templates

These templates are copy-ready starting points for reference-mask and crisis-map access requests. Replace bracketed placeholders before sending. Do not treat any source as redistributable until written terms are confirmed.

## Common Project Description

FloodGuard Thailand is a non-operational research and preparedness prototype that converts flood extent or probability inputs into local decision-support outputs: exposed population, likely road disruption, evacuation access loss, Evacuation Equity Gap, Flood Preparedness Priority Score, and compact action briefs.

The current repository does not publish official warnings, does not claim guaranteed real-time detection, and does not redistribute source imagery or crisis-map geometry unless licensing terms permit it.
