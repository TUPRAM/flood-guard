# Task 01 - Repo Scaffold

## Goal

Create a reviewable Python repository for FloodGuard Thailand.

## Context

The repo should support a small, testable vertical slice before remote-sensing complexity is added.

## Done When

- Package exists under `src/floodguard/`.
- Tests exist under `tests/`.
- Sample fixtures exist under `tests/fixtures/`.
- Durable docs exist under `docs/`.
- `pytest` runs successfully.
